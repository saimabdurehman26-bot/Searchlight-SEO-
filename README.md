# Searchlight SEO checker

A small interactive SEO-checking website with a Python backend. It uses only
Python's standard library, so no package installation is needed.

## Start the website

1. Open a terminal in this folder.
2. Run `python app.py`.
3. Open <http://127.0.0.1:8000> in your browser.
4. Press **Ctrl+C** in the terminal to stop the server.

The checker evaluates the page details you enter. It does not fetch or crawl
the URL; the URL is only checked for a readable slug containing your keyword.
